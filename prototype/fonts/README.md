# Fonts (not committed)

Horizon Power's brand font is **Beausite Classic** (Fatype). It is licensed for internal Horizon Power use only, so the font files are **not in this repo** and the public GitHub Pages site falls back to Inter.

To see the prototype in Beausite on your machine, put these four files in this folder (git ignores them):

```
BeausiteClassic-Regular.woff2
BeausiteClassic-Medium.woff2
BeausiteClassic-Semibold.woff2
BeausiteClassic-Bold.woff2
```

Then open `prototype/index.html` from your local copy. If Beausite Classic is installed on your computer, the prototype uses that even without these files.
